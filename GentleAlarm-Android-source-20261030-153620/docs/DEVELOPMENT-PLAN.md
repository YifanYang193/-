# Android 自用版开发计划

## 目标

在 Windows 免费开发，生成 APK 安装到自己的安卓手机。无需上架、开发者付费账号、服务器或 GitHub。
主功能为锁屏定时响铃，音量从很轻逐渐增大；平时无需应用整夜运行。
测试设备：**Redmi Note 10，Android 11（API 30）**，MIUI 具体版本待补充。

## 技术选择

- Java + Android 原生界面；minSdk 26、compileSdk / targetSdk 35。
- AlarmManager.setAlarmClock 负责定时，Receiver 到点启动媒体前台服务。
- MediaPlayer 循环播放恒定音量音频，按实际经过时间平滑提高应用音量，到上限保持。
- 闹钟音频属性 USAGE_ALARM，不修改系统全局音量，不申请勿扰绕过权限。
- 响铃时创建通知，支持停止和贪睡；全屏入口遵循系统授权。
- 设备保护存储只保存非敏感设置，重启后可在首次解锁前重新注册未来闹钟。
- 开机接收器只恢复定时，不在开机广播里启动媒体前台服务。

## 阶段与验收

| 阶段 | 工作 | 交付 / 验收 |
| --- | --- | --- |
| 一：迁移源代码 | 归档 iOS、建立 Android Gradle 项目、实现核心界面与响铃 | 本轮交付源代码和构建脚本 |
| 二：构建与安装 | 安装 Android Studio / SDK、本机生成 APK、USB 或手动安装 | APK 可成功构建并安装到手机 |
| 三：核心真机验证 | 权限、锁屏 1 分钟测试、长时锁屏、省电、渐强、停止、贪睡 | 真实设备上按预期触发并持续渐强 |
| 四：日常使用适配 | 根据手机品牌处理自启动 / 后台限制、验证重启及更新 | 连续多晚试用并记录结果 |
| 五：体验完善 | 按需求增加每周重复、多闹钟和其他音色 | 核心可靠性验证通过后再扩展 |

晨光功能后置，不以整夜常亮为前提；是否实现响铃时渐亮，另行评估设备锁屏策略。

## 首版明确范围

一个待响的一次性闹钟；时间编辑通过新设置替换旧设置。
渐强时长 10 / 30 / 60 / 120 / 180 秒；应用播放上限 10%～100%；贪睡 5 分钟；响铃 10 分钟自动停止。
每次响铃结束后需重新设置第二天闹钟，尚无每天自动重复。
试听在前台播放 30 秒，长渐强的试听不会自动快进到上限。

## 费用与交付方式

Android Studio、SDK、Gradle、自签名安装均无需开发者会员费用。
本机编译不要求代码公开。APK 无 7 天续签规则；更新时必须保持包名和签名一致。
后续如使用商店或第三方云服务，需要另行核实条款，不属于当前自用方案。

## 风险与验证边界

设备型号和 Android 版本已确认；MIUI 具体版本、权限菜单、后台策略及锁屏表现待真机确认。
Android 11 不需要 Android 12+ 精确闹钟特殊授权、Android 13+ 通知运行时授权及 Android 14+ 全屏特殊授权；仍须验证 MIUI 自启动、省电策略及锁屏通知。
不承诺关机、强制停止、通知 / 定时权限被撤销后仍能正常唤醒。
首次真机验证通过前使用系统自带闹钟兜底。
